## 🚀 Run Locally

```bash
git clone https://github.com/abhisheksharma611/Abhishek-Kumar-T.git
cd Abhishek-Kumar-T
npm install
npm run dev      # → http://localhost:3000
```

| Command | Purpose |
|-------------------|--------------------------------|
| `npm run dev` | Dev server (Turbopack, HMR) |
| `npm run build` | Production build |
| `npm start` | Serve production build |
| `npm run lint` | ESLint |
| `npm test` | Vitest suite |

## 🔐 Environment Variables

| Variable | Required | Description |
|---------------|----------|----------------------------------------------------|
| `EMAIL_USER` | ✅ | Gmail address that sends contact-form emails |
| `EMAIL_PASS` | ✅ | Gmail App Password (16 chars) |

🔒 Never commit `.env.local` — it's gitignored. On Vercel, set these as **Sensitive** env vars.
